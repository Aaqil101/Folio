# AGENTS.md

## Project

Folio turns PDFs into print-ready booklets (two-up imposition). Plain Python, no framework. `main.py` boots the PySide6 window (`ui/` package); the `core/` modules keep their own `__main__` blocks.

## Commands

- Environment: `.venv` (Python 3.14.7). Install deps with `pip install -r requirements.txt` (fully pinned).
- Always run from the repo root as modules — imports are package-absolute (`from core.calculation import impose`), so `python core/booklet_imposition.py` fails; use `python -m core.<module>`:
  - `python -m core.generate_test_pdf --help` — argparse CLI that builds numbered test PDFs (reportlab).
  - `python -m core.generate_test_images --help` — argparse CLI that builds numbered test images (Pillow) in batches under `test_pdfs/images/<folder>/`; the counterpart to `generate_test_pdf`, test input for image support (issue #7).
  - `python -m core.booklet_imposition` — interactive: one prompt for both paths, shlex-split (e.g. `"in.pdf" "out.pdf"`). Stamps → imposes → verifies → saves.
  - `python -m core.calculation` — interactive: prints the imposition order for a page count.
  - `python -m core.verify_booklet SOURCE BOOKLET` — argparse CLI: re-derives the order from the source and verifies the imposed booklet. Exit 0 all pass, 1 any FAIL, 2 bad args / passworded source.
  - `python -m core.manual_test_suite` — runs the by-eye suite: builds synthetic inputs, imposes every PDF in `test_pdfs/inputs/` (synthetic + real), writes outputs and a checklist to `test_pdfs/`. Flags: `--quick` (≤200-page inputs, 12-sheet geometry sample), `--regen` (rebuild synthetic inputs), `--only SUBSTRING`, `--offline`, `--no-geometry`, `--sample N` (geometry sheet sample; 0 = every sheet, default 48), `--force` (bypass cache), `--list` (dry run). Missing real PDFs auto-download (retried, `%PDF`-validated). Beyond `build_booklet()`'s stamp verification it pixel-diffs each output against an independently rebuilt expected imposition (geometry oracle; sampled at 48 sheets for big files), and an oracle canary first proves the check can fail. Results are cached in `test_pdfs/run_cache.json` keyed on input mtime + code hash + sample size; failures dump PNG/log artifacts to `test_pdfs/failures/<stem>/`. Prints a summary table; exits non-zero on failures.
- `python -m main` — launches the PySide6 window (issue #2): **job queue table** for multiple PDFs (sub-issue #13), each with input/output paths, real settings (sub-issue #12), and **wired imposition** (sub-issue #11) — the Create booklets button runs `build_booklet()` for each job with status-bar progress and `PopupWindow` result popups. Boots a pinned accent from `utils/config.py` before `build_stylesheet()` if one is saved. The app-wide stylesheet is assembled by `ui/styles/build_styles.py`.
- No lint, typecheck, or test framework exists. "Testing" = manual script runs checked by eye: `print(order)`, then `Verifying N sheets...`, per-sheet `FAIL` lines, and `Result: X/Y sheets passed`. **Do not introduce pytest/unittest or new tooling unless asked** — this is a deliberate project convention (GitHub issues #9/#10).
- Verification runs inside `build_booklet()`, which raises `BookletVerificationError` on failure (nothing is written); `verify_booklet.py` also has a standalone CLI.

## Commits

- Commit only when explicitly asked, then **one commit per file or logical change** — don't bundle unrelated edits.
- Message style: a short imperative summary line (sentence case), followed by a body of `- ` bullet descriptions of what changed. Examples in `git log` (e.g. `Derive verifier width from shared A4 constants`).
- Check `git status`/`git diff` before staging; stage files individually rather than `git add -A`.

## Architecture

- `core/calculation.py` — `impose(number_pages)` returns `(left, right)` 1-based page-number pairs. Page count pads to a multiple of 4; `0` is the sentinel for a blank/padding side.
- `core/booklet_imposition.py` — `build_booklet(input_path, output_path, sheet_size=A4_LANDSCAPE)`: rejects passworded sources (`needs_pass` guard), clears `/Rotate` flags first (`page.set_rotation(0)` — stored content is imposed as-is, labels align across halves; `show_pdf_page()` mishandles sources that still carry rotation, shifting and clipping them), stamps every source page with an invisible 4-digit page number (`render_mode=3`, PDF operator `Tr 3`), then imposes and verifies — the whole pipeline is PyMuPDF-only (no `io.BytesIO` bridging; fitz-only `build_booklet()` landed in `1c87042`). The helper `place_pages_side_by_side(..., sheet_size=A4_LANDSCAPE)` is fitz-only: `output.new_page()` + `show_pdf_page()`, sheet from `sheet_size` (`SHEET_SIZES` from `utils/constants.py`; the CLI and suite never pass it, so they stay A4), half-width `sheet_size[0] / 2` splits left/right, `None` side = blank half. `sheet_size` is threaded into `verify_booklet()` so stamps land in the right halves on A3/A5 sheets (issue #12).
- `core/verify_booklet.py` — `stamp_page_numbers()` + `verify_booklet(output, order, sheet_size=A4_LANDSCAPE) -> bool` (half-width derived from `sheet_size`, not the module `HALF_WIDTH` constant, which is kept for imports), plus `BookletVerificationError` and a standalone CLI (`python -m core.verify_booklet SOURCE BOOKLET`). fitz-only; the migration-era `isinstance` branch and its `io`/`pikepdf` imports are gone, and pikepdf is out of `requirements.txt` (`450cef8`). `build_booklet()` raises instead of ignoring a failed verification (issue #9).
- `core/manual_test_suite.py` — the by-eye test suite (issue #10): generates synthetic inputs (odd/even, rotated, mixed sizes, asymmetric, annotations, encrypted, 500-page stress), auto-downloads the real corpus, imposes everything under `test_pdfs/inputs/`, outputs to `test_pdfs/outputs/`, and validates each output with an independent geometry oracle (rebuild expected sheets from the input, pixel-diff vs actual; >10% content diff = fail). An oracle canary (impose → assert pass, blacken a sheet → assert fail) runs before the suite so a dead check can't mask regressions. Run results cache in `test_pdfs/run_cache.json` (input size/mtime + sha of the core sources); `--force` re-runs, `--list` previews. Failure artifacts land in `test_pdfs/failures/<stem>/` (actual/expected/diff PNGs, `verify.log`). `show_pdf_page()` drops annotations/bookmarks by design; passworded inputs are rejected via a `needs_pass` guard in `build_booklet()`.
- `core/page_info.py` — `count_pages(path) -> int | None`: cheap page count via the PDF trailer (`fitz.open`); `None` for missing/corrupt/password-protected files. Used by the job queue's Pages column; keeps fitz out of the UI.
- `utils/format_utils.py` — `zero_padding(n, width=2)` used at **width=4** for stamps and `_check_side()`, but `generate_test_pdf.py` uses the width=2 default for the visible number. Keep stamp and check in sync; the visible number is never matched by the verifier.
- `utils/constants.py` — `PAGE_WIDTH`/`PAGE_HEIGHT` are portrait A4 (reportlab) for the test PDF; `A4_LANDSCAPE` (841.89 × 595.28) is the shared source for the imposition sheet and the verifier's `HALF_WIDTH`; `SHEET_SIZES` maps `A3`/`A4`/`A5` → landscape tuples (the settings sheet-size picker). Also holds the UI constants (`FONT_FAMILY`, `FONT_SIZE_HEADER`, `BORDER_RADIUS*`) and app metadata (`APP_NAME`, `APP_VERSION`, `AUTHOR`, `DESCRIPTION`, `WEBSITE_URL`) ported from Obsidian-Forge.
- `utils/config.py` — `Config` (OF port): JSON settings in `%APPDATA%\Folio\settings.json` (`%APPDATA%` missing → `~/.folio/`), one shared file keyed by sanitized `os.getlogin()`, `version` bumped each save. Properties: `accent` (`"random"` or accent name), `default_output_dir` (`""` = next to input), `auto_open_output`, `open_output_mode` (`reveal`|`open`), `output_filename_template`, `confirm_overwrite`, `clear_log_per_run`, `sheet_size` (key into `SHEET_SIZES`), `persist_queue`, `auto_open_mode` (`none`|`last`|`all`), `job_queue` (list of `{input, output}` dicts when `persist_queue` enabled). Module singleton `config` — UI imports that; `core/` must not (core stays config-free).
- `main.py` — the GUI entrypoint: `QApplication` → `app.setStyle("Fusion")` (same trick as Blender-Launcher-V2: Fusion paints the combo popup itself, so Windows 11's native rounded frame never appears on dropdowns — the QSS alone can't reach `QComboBoxPrivateContainer`) → pin saved accent (`AccentTheme.pin(config.accent)` when not `"random"`, **before** `build_stylesheet()` so the QSS bakes it in) → `MainWindow().show()`.
- `ui/main_window.py` — `MainWindow(QMainWindow)` (issue #2): **header bar** (`#HeaderBar`, one 44px row) with the **job toolbar** on the left — Add/Edit/Delete/Clear All/Refresh (`HoverIconButtonSVG`) — then a `#HeaderSeparator` 1px vertical divider, then **About + Settings + Log** `QToolButton`s right (no app heading; `MainToolButton` property; the header and toolbar were merged into this single bar), **job queue table** (`#JobTable`, `QTableWidget`) with **Input PDF | Pages | Output PDF** columns — the Pages cell shows `167 → 84` (`count_pages()` + `calculate_pages() // 2`; `—` when unreadable) with a tooltip breaking it down to padded blanks, booklet pages, and duplex sheets; a missing input paints the path red, an already-existing output paints it yellow — path cells are drawn by the nested `_PathDelegate` as **two lines** (filename on top in the item's foreground color, dimmed folder below, both middle-elided; the full path stays in the item text and tooltip), with 40px rows (`_PathDelegate.ROW_HEIGHT` drives `verticalHeader().setDefaultSectionSize`) — drag-reorder rows (`InternalMove`; jobs are matched after a drop via an `id(job)` stamped in the input item's `Qt.UserRole`, never by path text, so duplicates stay distinct), drag & drop PDFs onto table, context menu (Add/Edit/Delete/Duplicate), keyboard shortcuts handled window-level by `eventFilter` on both the window and the table (`Del`/`Ctrl+N`/`Enter`/`F2`/`Ctrl+Return` — Ctrl+Return is checked **before** bare Return, and a modal-dialog guard defers to open dialogs), empty-state placeholder (overlay `#EmptyStateLabel` on the table viewport, toggled by `_update_empty_state` — never a cell widget, which Qt rejects on a 0-row table). Footer with status label + **Create booklets** (`HoverIconButtonSVG[SaveButton]`). Batch processing runs `build_booklet()` per job with `_ProgressPipe` mirroring stdout to status bar + `LogWindow`, verification failure shows popup then continues queue; the loop is guarded against re-entry (`_batch_running` disables the table/toolbar mid-run because `_ProgressPipe` pumps `processEvents()`). `config.persist_queue` saves/restores queue across sessions (`_save_queue` also **pops** the stored list when the setting is off so stale queues can't linger); `config.auto_open_mode` (`none|last|all`) controls post-queue open behavior. Edit opens `JobDialog` (output stays user-editable); Add keeps the multi-file picker with auto-suggested outputs. Settings dialog (`SettingsDialog`) updates reflected live via `_refresh_accent_icons()`.
- `ui/job_dialog.py` — `JobDialog(input_path, output_path, suggest=...)`: Edit-job dialog — read-only input row + Browse (`getOpenFileName`, `.pdf`), free-text output row + Browse (`getSaveFileName`), inline `#JobWarningLabel` validated live on `textChanged` (required, `.pdf` suffix, existing parent folder, input file exists); `accept()` auto-appends `.pdf` to a suffix-less output and blocks while a warning shows. Changing the input re-suggests the output only when it is empty or still the previous suggestion (via the `suggest` callable — `MainWindow._suggested_output`). Save/Cancel buttons mirror `SettingsDialog` (Ctrl+Return/Esc).
- `ui/settings.py` — the real `SettingsDialog` (issue #12): `QScrollArea` + `SettingsGroup`s — **Appearance** (accent combo Random/Blue/Brown/Red/Purple/Green/Gray), **Input** (default folder for the Open PDF dialog), **Output** (default-folder row, filename pattern with `{stem}` + `.pdf` auto-append, "Ask before overwriting" checkbox), **After saving** (show-after-save checkbox + open-PDF-vs-reveal-in-Explorer, disabled until auto-show is on), **Sheet size** (A3/A4/A5), **Log** (clear before each run), **Queue** (persist queue checkbox, auto-open mode: None/Last/All). Save (`SaveButton`) persists via `config.save_settings()`; if the accent changed it re-pins `AccentTheme`, rebuilds the app stylesheet live, and calls the parent's `_refresh_accent_icons()`. Cancel (`CancelButton`) rejects without persisting. Checkboxes use `square_check*` icons via `_set_check_icon()` (the QSS hides checkbox indicators); folder rows share `_build_folder_row()`. The sections behave as an **accordion**: they all start collapsed, and expanding one collapses the others (`_add_section` registers each `SettingsGroup`, `_on_section_toggled` collapses siblings via the group's `collapsed` signal).
- `ui/widgets/` — `SettingsGroup` (originally ported from Obsidian-Forge, now an ordinary Folio file): collapsible card with a `CollapseButton` chevron, plain label or checkable variant, optional action button; uses `SectionHeader`/`SettingsGroup` QSS properties and `FONT_SIZE_HEADER`, exposes a `collapsed(bool)` signal (the settings accordion listens to it). The package `__init__` re-exports `SettingsGroup`.
- `ui/styles/` — the QSS system, originally copied from Obsidian-Forge: one module per widget exposing `qss()`, auto-collected by `build_styles.build_stylesheet()` (pkgutil scan). **These files are ordinary Folio files — edit them freely; no Obsidian-Forge sync is required** (user decision). `QTableView.py`/`QMenu.py` style the queue table and context menu; `QComboBox.py` keeps the dropdown popup square (`border-radius: 0px`) to match the closed combo. Folio-only rules live in `ui/styles/folio.py`, which the scan picks up automatically: `#JobTable` (alternating rows, hover, selection with accent border, header), `#HeaderBar HoverIconButtonSVG` (job-toolbar buttons — the `#HeaderBar` frame itself, incl. its bottom border and the `#HeaderSeparator` divider, is styled in `QWidget.py`), `#EmptyStateLabel`, `#QueueStatusLabel`, `#JobContextMenu` (objectName-pinned menu rules), `#JobWarningLabel` (dialog validation red), and `QPushButton[SaveButton]:disabled`. The legacy `#JobToolbar` frame rule went away when the header and toolbar merged into one bar. The legacy `#UploadButton`/`#InputPathLabel` rules were removed with the single-input layout.
- `utils/color.py` / `utils/resources.py` / `utils/hover_button.py` — vendored from Obsidian-Forge: Tokyo Night palette + `AccentTheme` (random accent chosen once per session), `get_icon(name, color)` (SVG recoloring via `QSvgRenderer`, loads `:/assets/...` Qt resources with a file fallback), and `HoverIconButtonSVG` (icon recolors on hover/press). Deliberate divergences from OF: in `resources.py` the file-fallback root is `.parent.parent` (Folio's `utils/` sits at the repo root, OF's is nested under `src/`), `import resources_rc` lives **inside** the try/except so the documented file-path fallback actually engages when `resources_rc.py` is missing, and the recolor path renders **256×256** instead of OF's hardcoded 24×24 (which capped large icons — the About dialog's 72px app icon came out tiny); in `color.py` **`AccentTheme.pin(name)`** was added for issue #12 (pins a named accent, or clears the pin for `"random"` — OF has no equivalent).
- `assets/` + `resources.qrc` + compiled `resources_rc.py` — the asset tree copied from `D:\GitHub\Obsidian-Forge` (user pruned what Folio doesn't need — the qrc is now trimmed to the survivors, so **keep qrc and `assets/` in sync**). The app icon is `assets/application/folio.svg` (Phosphor Icons `book-open-text`, MIT — license noted in the file header), used for the window icon and the About dialog; it keeps `fill="currentColor"`, so always pass `color=` to `get_icon()` for it. After changing assets, recompile with `.venv\Scripts\pyside6-rcc.exe resources.qrc -o resources_rc.py`; `resources_rc.py` is tracked, same as in Obsidian-Forge.
- PyMuPDF's import name is `fitz`.

## Environment quirks

- `gh` CLI may not be on PATH in fresh shells — fall back to the full path if `Get-Command gh` fails (this machine: `C:\Program Files\GitHub CLI\gh.exe`).
- Windows consoles defaulting to cp1252 choke on the `→` in `generate_test_pdf.py`'s final `print` (`UnicodeEncodeError`) — prefix runs with `$env:PYTHONUTF8=1`.
- Default branch is `master`, not `main`.
