# AGENTS.md

## Project

Folio turns PDFs into print-ready booklets (two-up imposition). Plain Python, no framework. `main.py` boots the PySide6 window (`ui/` package); the `core/` modules keep their own `__main__` blocks.

## Commands

- Environment: `.venv` (Python 3.14.7). Install deps with `pip install -r requirements.txt` (fully pinned).
- Always run from the repo root as modules — imports are package-absolute (`from core.calculation import impose`), so `python core/booklet_imposition.py` fails; use `python -m core.<module>`:
  - `python -m core.generate_test_pdf --help` — argparse CLI that builds numbered test PDFs (reportlab).
  - `python -m core.generate_test_images --help` — argparse CLI that builds numbered test images (Pillow) in batches under `test_pdfs/images/<folder>/`; the counterpart to `generate_test_pdf`, test input for image support (issue #7). `--dpi 0` saves without dpi metadata; `--exif-orientation {1,3,6,8}` (JPEG only, repeatable/cycled) writes an EXIF orientation tag with the stored pixels pre-rotated the inverse way so `exif_transpose()` recovers the upright image.
  - `python -m core.image_booklet IMG [IMG ...] -o OUT [--sheet A4] [--keep-order]` — image-set CLI (issue #7): files and folders (expanded recursively, natural-sorted unless `--keep-order`), wrapped into a one-page-per-image PDF (DPI normalized to the highest valid dpi in the set, missing metadata = already at target so never upscaled), then imposed via `impose_document()`. Same output/exit behaviour as the other CLIs (verify lines, exit 1 on failure).
  - `python -m core.booklet_imposition` — interactive: one prompt for both paths, shlex-split (e.g. `"in.pdf" "out.pdf"`). Stamps → imposes → verifies → saves.
  - `python -m core.calculation` — interactive: prints the imposition order for a page count.
  - `python -m core.verify_booklet SOURCE BOOKLET` — argparse CLI: re-derives the order from the source and verifies the imposed booklet. Exit 0 all pass, 1 any FAIL, 2 bad args / passworded source.
  - `python -m core.manual_test_suite` — runs the by-eye suite: builds synthetic inputs, imposes every PDF in `test_pdfs/inputs/` (synthetic + real), writes outputs and a checklist to `test_pdfs/`. Flags: `--quick` (≤200-page inputs, 12-sheet geometry sample), `--regen` (rebuild synthetic inputs), `--only SUBSTRING`, `--offline`, `--no-geometry`, `--sample N` (geometry sheet sample; 0 = every sheet, default 48), `--force` (bypass cache), `--list` (dry run). Missing real PDFs auto-download (retried, `%PDF`-validated). Beyond `build_booklet()`'s stamp verification it pixel-diffs each output against an independently rebuilt expected imposition (geometry oracle; sampled at 48 sheets for big files), and an oracle canary first proves the check can fail. Results are cached in `test_pdfs/run_cache.json` keyed on input mtime + code hash + sample size; failures dump PNG/log artifacts to `test_pdfs/failures/<stem>/`. Prints a summary table; exits non-zero on failures. Image folders under `test_pdfs/images/` join the run as **image-set inputs** (`TestInput` with `kind="images"`, built via `core.image_booklet`, per-file size/mtime fingerprint); `ensure_image_inputs()` generates the deterministic `suite_mixed` (12 PNGs, mixed 150/300 dpi), `suite_tiff` (6 TIFFs @ 300), `suite_nodpi` (6 PNGs, no dpi metadata), `suite_exif` (4 JPEGs, EXIF orientations 1/6/8/3), `suite_webp` (4 WebP), and the original `issue7_png`/`issue7_jpg` dev batches (now auto-generated too, byte-identical recipes) alongside the synthetic PDFs, and `--regen` rebuilds both.
- `python -m main` — launches the PySide6 window (issue #2): **job queue table** for multiple PDFs (sub-issue #13), each with input/output paths, real settings (sub-issue #12), and **wired imposition** (sub-issue #11) — the Create booklets button runs `build_booklet()` for each job with status-bar progress and `PopupWindow` result popups. Boots a pinned accent from `utils/config.py` before `build_stylesheet()` if one is saved. The app-wide stylesheet is assembled by `ui/styles/build_styles.py`.
- No lint, typecheck, or test framework exists. "Testing" = manual script runs checked by eye: `print(order)`, then `Verifying N sheets...`, per-sheet `FAIL` lines, and `Result: X/Y sheets passed`. **Do not introduce pytest/unittest or new tooling unless asked** — this is a deliberate project convention (GitHub issues #9/#10).
- Verification runs inside `build_booklet()`, which raises `BookletVerificationError` on failure (nothing is written); `verify_booklet.py` also has a standalone CLI.

## Commits

- Commit only when explicitly asked, then **one commit per file or logical change** — don't bundle unrelated edits.
- Message style: a short imperative summary line (sentence case), followed by a body of `- ` bullet descriptions of what changed. Examples in `git log` (e.g. `Derive verifier width from shared A4 constants`).
- Check `git status`/`git diff` before staging; stage files individually rather than `git add -A`.

## Architecture

- `core/calculation.py` — `impose(number_pages)` returns `(left, right)` 1-based page-number pairs. Page count pads to a multiple of 4; `0` is the sentinel for a blank/padding side.
- `core/booklet_imposition.py` — `build_booklet(input_path, output_path, sheet_size=A4_LANDSCAPE)`: rejects passworded sources (`needs_pass` guard), clears `/Rotate` flags first (`page.set_rotation(0)` — stored content is imposed as-is, labels align across halves; `show_pdf_page()` mishandles sources that still carry rotation, shifting and clipping them), stamps every source page with an invisible 4-digit page number (`render_mode=3`, PDF operator `Tr 3`), then imposes and verifies — the whole pipeline is PyMuPDF-only (no `io.BytesIO` bridging; fitz-only `build_booklet()` landed in `1c87042`). The helper `place_pages_side_by_side(..., sheet_size=A4_LANDSCAPE)` is fitz-only: `output.new_page()` + `show_pdf_page()`, sheet from `sheet_size` (`SHEET_SIZES` from `utils/constants.py`; the CLI and suite never pass it, so they stay A4), half-width `sheet_size[0] / 2` splits left/right, `None` side = blank half. `sheet_size` is threaded into `verify_booklet()` so stamps land in the right halves on A3/A5 sheets (issue #12). Split for image reuse (issue #7): **`impose_document(source_doc, output_path, sheet_size)`** does the whole job on an already-open document (rotate-clear → stamp → impose → place → verify → save), and `build_booklet()` is a thin file wrapper that raises `ValueError` with a `core.image_booklet` hint for non-PDF inputs (fitz opens images as `is_pdf == False` one-pagers that refuse stamping/`show_pdf_page`).
- `core/image_booklet.py` — image input (issue #7): `IMAGE_EXTENSIONS` (`.jpg/.jpeg/.png/.tif/.tiff/.webp`) + `is_image_path()`, `natural_sort()` (digit-aware: `page2` < `page10` — the CLI/drop default order), `collect_images()` (expand directories recursively, reject non-image files), `_read_image_meta()` (Pillow, no pixel decode: size + X dpi + EXIF orientation; a dpi is valid only in `2..4000`, which kills TIFF's stock `(1, 1)`), `build_image_document(paths)` (one page per image, **preserves the given order** — callers sort first: target dpi = highest valid in the set else `DEFAULT_DPI` 72; `effective_dpi` = own valid dpi else target, so dpi-less images are treated as already normalized and never upscaled; resample with `exif_transpose` + LANCZOS only when `effective != target` or the EXIF orientation turns, re-encode lossless PNG via `insert_image(stream=...)`. Direct file embed is only for formats MuPDF decodes natively (`_FITZ_NATIVE` = JPEG/PNG/TIFF — **MuPDF 1.27.2 cannot decode WebP** (`FzErrorFormat: unknown image file format`), so WebP takes the Pillow decode → PNG path even at equal dpi); page box = px/effective×72 pt — physical size preserved), `build_image_booklet()` (wrap + `impose_document()`), and the CLI. Unreadable file → `ValueError("Cannot read image: ...")` (the UI popup and suite ERROR row surface it unchanged). No Qt/`utils.config` imports — core stays config-free.
- `core/verify_booklet.py` — `stamp_page_numbers()` + `verify_booklet(output, order, sheet_size=A4_LANDSCAPE) -> bool` (half-width derived from `sheet_size`, not the module `HALF_WIDTH` constant, which is kept for imports), plus `BookletVerificationError` and a standalone CLI (`python -m core.verify_booklet SOURCE BOOKLET`). fitz-only; the migration-era `isinstance` branch and its `io`/`pikepdf` imports are gone, and pikepdf is out of `requirements.txt` (`450cef8`). `build_booklet()` raises instead of ignoring a failed verification (issue #9).
- `core/manual_test_suite.py` — the by-eye test suite (issue #10): generates synthetic inputs (odd/even, rotated, mixed sizes, asymmetric, annotations, encrypted, 500-page stress), auto-downloads the real corpus, imposes everything under `test_pdfs/inputs/`, outputs to `test_pdfs/outputs/`, and validates each output with an independent geometry oracle (rebuild expected sheets from the input, pixel-diff vs actual; >10% content diff = fail). An oracle canary (impose → assert pass, blacken a sheet → assert fail) runs before the suite so a dead check can't mask regressions. Run results cache in `test_pdfs/run_cache.json` (input size/mtime + sha of the core sources); `--force` re-runs, `--list` previews. Failure artifacts land in `test_pdfs/failures/<stem>/` (actual/expected/diff PNGs, `verify.log`). `show_pdf_page()` drops annotations/bookmarks by design; passworded inputs are rejected via a `needs_pass` guard in `build_booklet()`. Input collection is `TestInput`-based (`name` = output filename, `paths`, `kind` pdf|images, plus `build()`/`source()`/`fingerprint()`): PDFs as before, and every image folder under `test_pdfs/images/` with ≥1 supported file joins as an image-set input (imposed via `core.image_booklet`); `ensure_image_inputs(regen)` (re)generates `suite_mixed` (12 PNGs, mixed 150/300 dpi) and `suite_tiff` (6 TIFFs @ 300) via `generate_test_images()`. The geometry oracle stamps a **fresh** `TestInput.source()` (never the build's document — LANCZOS + PNG encode is deterministic). Cache key stays the output name; fingerprint is `size:mtime_ns` per file, joined with `+` for sets (touch one image → the set re-runs); `CODE_PATHS` now includes `core/image_booklet.py` and `core/generate_test_images.py`.
- `core/page_info.py` — `count_pages(path) -> int | None`: cheap page count via the PDF trailer (`fitz.open`); `None` for missing/corrupt/password-protected files. Used by the job queue's Pages column; keeps fitz out of the UI.
- `utils/format_utils.py` — `zero_padding(n, width=2)` used at **width=4** for stamps and `_check_side()`, but `generate_test_pdf.py` uses the width=2 default for the visible number. Keep stamp and check in sync; the visible number is never matched by the verifier.
- `utils/constants.py` — `PAGE_WIDTH`/`PAGE_HEIGHT` are portrait A4 (reportlab) for the test PDF; `A4_LANDSCAPE` (841.89 × 595.28) is the shared source for the imposition sheet and the verifier's `HALF_WIDTH`; `SHEET_SIZES` maps `A3`/`A4`/`A5` → landscape tuples (the settings sheet-size picker). Also holds the UI constants (`FONT_FAMILY`, `FONT_SIZE_HEADER`, `BORDER_RADIUS*`) and app metadata (`APP_NAME`, `APP_VERSION`, `AUTHOR`, `DESCRIPTION`, `WEBSITE_URL`) ported from Obsidian-Forge.
- `utils/config.py` — `Config` (OF port): JSON settings in `%APPDATA%\Folio\settings.json` (`%APPDATA%` missing → `~/.folio/`), one shared file keyed by sanitized `os.getlogin()`, `version` bumped each save. Properties: `accent` (`"random"` or accent name), `default_output_dir` (`""` = next to input), `default_input_dir` (`""` = OS default), `default_folder_dir` (`""` = fall back to `default_input_dir`; the Add Folder picker's start dir), `image_view_mode` (`"list"`|`"thumbnails"`, default `"list"` — the image-set dialog layout), `auto_open_output`, `open_output_mode` (`reveal`|`open`), `output_filename_template`, `confirm_overwrite`, `clear_log_per_run`, `sheet_size` (key into `SHEET_SIZES`), `persist_queue`, `auto_open_mode` (`none`|`last`|`all`), `job_queue` (list of `{input, output}` dicts when `persist_queue` enabled). Module singleton `config` — UI imports that; `core/` must not (core stays config-free).
- `main.py` — the GUI entrypoint: `QApplication` → `app.setStyle("Fusion")` (same trick as Blender-Launcher-V2: Fusion paints the combo popup itself, so Windows 11's native rounded frame never appears on dropdowns — the QSS alone can't reach `QComboBoxPrivateContainer`) → pin saved accent (`AccentTheme.pin(config.accent)` when not `"random"`, **before** `build_stylesheet()` so the QSS bakes it in) → `MainWindow().show()`.
- `ui/main_window.py` — `MainWindow(QMainWindow)` (issue #2): **header bar** (`#HeaderBar`, one 44px row) with the **job toolbar** on the left — Add File/Add Folder/Edit/Delete/Clear All/Refresh (`HoverIconButtonSVG`; `folder_btn` → `_add_folder()`) — then a `#HeaderSeparator` 1px vertical divider, then **About + Settings + Log** `QToolButton`s right (no app heading; `MainToolButton` property; the header and toolbar were merged into this single bar), **job queue table** (`#JobTable`, `QTableWidget`) with **Input PDF | Pages | Output PDF** columns — the Pages cell shows `167 → 84` (`count_pages()` + `calculate_pages() // 2`; `—` when unreadable) with a tooltip breaking it down to padded blanks, booklet pages, and duplex sheets; a missing input paints the path red, an already-existing output paints it yellow — path cells are drawn by the nested `_PathDelegate` as **two lines** (filename on top in the item's foreground color — unless a `Qt.UserRole+1` label is set, which the delegate prefers, so image-set rows show `first +N` e.g. `cover.png +11` — dimmed folder below, both middle-elided; the full path stays in the item text and tooltip), with 40px rows (`_PathDelegate.ROW_HEIGHT` drives `verticalHeader().setDefaultSectionSize`) — drag-reorder rows (`InternalMove`; the drop runs the shared manual move from `ui/reorder.py`; jobs are matched after a drop via an `id(job)` stamped in the input item's `Qt.UserRole`, never by path text, so duplicates stay distinct), drag & drop PDFs onto table, context menu (Add File / **Add Folder** / Edit / Delete / Duplicate, plus **Reorder Images** on image-set rows only → `_reorder_job_images()` reopens `ImageSetDialog` and updates `image_paths`/`input_path`/`input_pages`), keyboard shortcuts handled window-level by `eventFilter` on both the window and the table (`Del`/`Ctrl+N`/`Enter`/`F2`/`Ctrl+Return` — Ctrl+Return is checked **before** bare Return, and a modal-dialog guard defers to open dialogs), empty-state placeholder (overlay `#EmptyStateLabel` on the table viewport, toggled by `_update_empty_state` — never a cell widget, which Qt rejects on a 0-row table). Footer with status label + **Create booklets** (`HoverIconButtonSVG[SaveButton]`). Batch processing runs `build_booklet()` per job with `_ProgressPipe` mirroring stdout to status bar + `LogWindow`, verification failure shows popup then continues queue; the loop is guarded against re-entry (`_batch_running` disables the table/toolbar mid-run because `_ProgressPipe` pumps `processEvents()`). `config.persist_queue` saves/restores queue across sessions (`_save_queue` also **pops** the stored list when the setting is off so stale queues can't linger); `config.auto_open_mode` (`none|last|all`) controls post-queue open behavior. Edit opens `JobDialog` (output stays user-editable); Add keeps the multi-file picker with auto-suggested outputs. Settings dialog (`SettingsDialog`) updates reflected live via `_refresh_accent_icons()`.
- `ui/job_dialog.py` — `JobDialog(input_path, output_path, suggest=...)`: Edit-job dialog — read-only input row + Browse (`getOpenFileName`, `.pdf`), free-text output row + Browse (`getSaveFileName`), inline `#JobWarningLabel` validated live on `textChanged` (required, `.pdf` suffix, existing parent folder, input file exists); `accept()` auto-appends `.pdf` to a suffix-less output and blocks while a warning shows. Save/Cancel buttons mirror `SettingsDialog` (Ctrl+Return/Esc).
- `ui/image_set_dialog.py` + image-job wiring — `ImageSetDialog(image_paths, parent)`: the reorder dialog, `#ImageSetTable` with **# | Filename | Size | DPI** (paths in the name item's `Qt.UserRole`), row drag reorder via `ui/reorder.py` (nested `_ImageTable.dropEvent` → `drop_event_moved()`; no `dragMoveEvent` override — Qt draws the indicator everywhere, empty area appends), Add images…/Remove/Sort by name, accept needs ≥1 row; rows arrive natural-sorted. **List/thumbnail views**: a `QStackedWidget` holds the table plus `#ImageSetGrid` (`QListWidget` IconMode + `InternalMove`), and two exclusive checkable `QToolButton`s in the hint row (`ViewToggle` property, `view_list.svg`/`view_thumbnail.svg`) switch them. Grid reorder is **not** stock `QListView` behavior — nested `_ImageGrid.dropEvent` routes through `drop_event_moved_grid()` (IconMode indicator comes from the *view*, not the event; foreign-source drops ignored, never `super()`, which can hard-crash), and `setMovement(Static)` must run **before** `setDragDropMode(InternalMove)` *plus* an explicit `grid.viewport().setAcceptDrops(True)` — `Static` resets the viewport's flag and `setAcceptDrops(True)` on the view alone is a no-op, so drops otherwise never reach the grid (Qt: `QWidgetWindow::findDnDTarget` walks up to the frame and the drop is ignored). Explicit `TILE_SIZE` on `setGridSize` + item `setSizeHint` (default (-1,-1) tiles vanish). Grid tiles show filename only with a 96px Pillow thumbnail (`exif_transpose`, cached per path, tooltip = path + size/dpi; unreadable = no icon). **Keyboard/button reorder**: `move_left_btn`/`move_right_btn` (`HoverIconButtonSVG`, `move_left.svg`/`move_right.svg`, icons-only 32×32 with BrowseButton styling, tooltips name the shortcut) run `_move_selected(±1)` — shifts the selected block one step (ascending for left, descending for right, skipping adjacent selected rows so contiguous/non-contiguous blocks keep relative order), then `_apply_paths()` + re-selects the moved rows (grid: `item.setSelected(True)`; table: `QItemSelection` with `Select|Rows` — `selectRow`/`select(idx,idx,flags)` don't accumulate); edge positions and empty selection are no-ops. Alt+Left/Alt+Right are wired **twice on purpose**: dialog-level `QShortcut`s (`WindowShortcut` context — fires whichever view has focus) *plus* an `Alt+Left/Right` branch in both views' `keyPressEvent` (the table otherwise swallows Alt+arrows as cell navigation; each path consumes the event so they never double-fire). One order flows through `_apply_paths()` (rebuilds both views); `image_paths` reads the **active** view — the pull is lazy on purpose, so Qt's post-drop bookkeeping (clearOrRemove) has always finished; opening layout comes from `config.image_view_mode` (in-dialog toggling does not persist); `_renumber()` keeps the # column in sync after table drops. In `ui/main_window.py`, `BookletJob` gains `image_paths: list[str] | None` where **`None` = PDF job and `[]` = image job with no images** (must fail validation, never silently become a PDF job); `_ingest_paths()` funnels the Add picker (filter now includes images), window drops, and the context-menu **Add Folder** entry (`_add_folder()` → `getExistingDirectory`; start dir = `config.default_folder_dir` falling back to `default_input_dir`) — **folders expand recursively** (`_expand_folder()`: PDFs natural-sorted into one job each, images via `collect_images()` into one set; a folder with nothing supported shows a status-bar note), `_files_from_mime()` accepts local folders alongside PDFs/images — images natural-sort into **one** queue row via `_prompt_image_job()` (PDFs from a mixed selection still land if the dialog is cancelled), `_suggested_image_output()` uses the shared parent folder's name when the set sits in one folder, the Pages cell shows `len(image_paths)`, the input-cell tooltip lists `Image set (N):` + paths, `_job_input_ok()` checks every file in the set, persistence writes an additive `"images"` key (old queues keep loading), and the batch runner calls `build_image_booklet()` vs `build_booklet()` inside the same `_ProgressPipe`/popups framework. In `ui/job_dialog.py`, the optional `image_paths` parameter switches the input row to `N images` + a **Reorder…** button and validates every file exists. - `ui/reorder.py` — shared manual row-move drop handling for both list widgets (`_ImageTable`/`_ImageGrid` + `MainWindow._JobTable`). Qt's built-in InternalMove can't be trusted: drops below the last row were rejected by the old guards, and `QTableWidget::dropEvent`'s take/set path blanks the source row (center drops) — so `drop_event_moved(view, event)` computes the insert point (`target_row_for_drop()`: indicator Above/Below/OnItem on a row, empty area → first row below y else `rowCount()`), moves the block itself (`move_rows()`: take cells descending, re-insert ascending at the target-adjusted index — cell data incl. `id(job)` UserRole stamps intact), then **`clearSelection()` + `acceptProposedAction()` without calling `super()`**: the flag that suppresses `QAbstractItemView::startDrag()`'s later `clearOrRemove()` lives inside Qt's own `dropEvent`, so clearing the selection makes the cleanup a no-op. `drop_event_moved_grid()` is the IconMode sibling (the drop indicator lives on the view, not the event). Returns `False` for external sources (caller falls back to `super()`, which the InternalMove gate rejects anyway; the grid never does). Pure helpers are offscreen-testable without a real drag (synthetic events can't satisfy Qt's `event->source() == this`).

## Environment quirks

- `gh` CLI may not be on PATH in fresh shells — fall back to the full path if `Get-Command gh` fails (this machine: `C:\Program Files\GitHub CLI\gh.exe`).
- Windows consoles defaulting to cp1252 choke on the `→` in `generate_test_pdf.py`'s final `print` (`UnicodeEncodeError`) — prefix runs with `$env:PYTHONUTF8=1`.
- Default branch is `master`, not `main`.
- PowerShell decodes native-command stdout with the console codepage (cp437), so `gh ... | Set-Content` corrupts UTF-8 into mojibake (`—` → `ΓÇö`, `…` → `ΓÇª`) — it corrupted issue #2's body once (fixed by re-encoding the damaged region with `text.encode("cp437").decode("utf-8")`). Use `cmd /c "gh ... > file"` for raw bytes, write input files with the editor tool + `gh --body-file` (safe), or set `[Console]::OutputEncoding = [Text.Encoding]::UTF8` first.
